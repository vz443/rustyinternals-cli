# rustyinternals-cli
Lightweight PE Parser cross platform for any windows executable

## Usage

Go to project root and "cargo run", cli interface will guide next, input pe file and analyse. 

Multi file analysis and json/toml output will be implemented down the line, cli itself will also have a refresh.

Currently working on the parsing modules for now, and then field validation, and only then i'll move to creating an interface, that serves more than just a test interface for me
